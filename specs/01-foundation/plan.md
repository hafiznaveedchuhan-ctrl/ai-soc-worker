## 3. Design details
- **Workspace:** `[tool.uv.workspace] members = ["packages/*", "services/*"]`; the root is a virtual (non-package)
  project with `[dependency-groups] dev = [...]`; soc-shared is `[tool.uv.sources] soc-shared = { workspace = true }`.
  Build backend `uv_build` (already in the scaffold). *Exact keys are confirmed in T01-01.*
- **models/** one module per area; enums are `StrEnum` (JSON as plain strings); `ConfigDict(extra="forbid")` by default,
  `frozen=True` for value objects. `TriageNote.to_text()` lives next to the model (single source of the template).
- **masking/**
  - `patterns.py` — compiled regexes (email, `DOMAIN\user`, IPv4 candidate, IPv6 candidate, token, internal FQDN).
  - `ipclass.py` — `classify_ip()` → public | private CIDR | special kind; `is_public_ip()`; uses `ipaddress` + an explicit
    list of documentation/CGNAT networks (because `is_global` differs across Python versions for some ranges; tested).
  - `maskmap.py` — `MaskMap` (dicts keyed by `(kind, normalised value)`; counters per kind; safe `__repr__`; `to_storage()`).
  - `text.py` — `mask_text`, `unmask`, `find_leaks`, `find_unmasked_pii`; replacements done with one regex pass per kind,
    skipping spans that are already tokens.
  - `alert.py` — `FIELD_KINDS` table (dotted path → kind), a recursive walker, `SECRET_KEY_RE` for dropped fields,
    `WELL_KNOWN_PRINCIPALS` kept unmasked.
- **settings.py** — `BaseServiceSettings(BaseSettings)` with `model_config = SettingsConfigDict(env_file=None, extra="ignore")`;
  services subclass it and set `env_prefix`. *API confirmed in T01-01 (pydantic-settings docs).*
- **demo_masking.py** — loads `tests/fixtures/win_4625.json`, prints BEFORE (fixture = lab values only), AFTER, `ip_context`,
  the token map with counts, and `find_unmasked_pii(after) == []` → "LEAK CHECK: OK".
- **Makefile** — `uv run --directory backend ...`-style targets; `help` is generated from `## ` comments.
- **CI** — `astral-sh/setup-uv` (pinned version) with Python 3.12; `uv sync --frozen --all-packages`; ruff, mypy, pytest
  `--cov=soc_shared --cov-fail-under=90`; gitleaks job with `fetch-depth: 0`. Path filters come in feature 10.

## 5. Test strategy
- Unit tests per FR; **property tests** (hypothesis): random IPv4/IPv6/emails embedded in random text → no leak,
  round-trip identity, idempotence; **golden tests** for `mask_alert` on 3 fixtures and for `TriageNote.to_text()`.
- Negative tests: public domains, timestamps, MACs, CIDRs, invalid IPs, well-known principals.
- No network (NFR-01-01). Everything is pure Python and runs in < 10 s.

## 6. Risks + mitigations
| Risk | Mitigation |
|---|---|
| Regex over- or under-masking | field-aware first, regex second; negative tests; the property test |
| IPv6 regex is complex | regex only finds candidates; `ipaddress` decides |
| `is_global` behaviour differs by Python patch level | explicit network lists + tests pinned to 3.12 |
| Hostname detection in free text misses short names (`WS01`) | learned-from-fields hostnames are masked everywhere after first sight; documented limit; 06's output guardrail re-checks |
| CI gitleaks action licensing for orgs | personal repo → free; else run the gitleaks binary (checked in T01-01) |
